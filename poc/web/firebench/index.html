Reading the two numbers. Shape agreement is the correlation between the two glows over the second half of the run — the measure every experiment in this project scored. Beside it is what a single still image of the fire scores on the same measure: a flame that barely moves is nearly perfectly predicted by one frame, so on the calm scenes that reference is above 0.99 and the model has no chance of beating it. On the gusty ones it drops to about 0.80 and the comparison becomes fair. Quoting one fixed number for it was a real error in this work, caught late.

What the model costs. Parcels per source is the runtime price: each is one Gaussian blob, and nothing carries over between frames, so any frame can be drawn at any time without the ones before it.
